# Developer Portfolio (React + React Bootstrap + Vite)

## Run
    npm install
    npm run dev       # http://localhost:5173
    npm run build     # production build in dist/

## Customize (no component edits needed)
- `src/data/profile.js` – name, bio, stats, contact, social links
- `src/data/projects.js`, `skills.js`, `experience.js`, `education.js`, `certifications.js`
- `public/resume.pdf` – replace with your resume
- `public/images/` – replace placeholder SVGs (profile + project screenshots)
- `src/index.css` – accent color is `--accent` at the top
- `src/components/Contact.jsx` – swap `sendMessage()` for EmailJS/Formspree/your API

Also update the title/meta tags in `index.html`.
